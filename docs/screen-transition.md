# 画面一覧・画面遷移仕様書

## 1. 画面一覧

|画面ID     |画面名              |目的                                       |
|:---------|:------------------|:------------------------------------------|
|SCR-001   |タイマー画面         |タイマーを設定し、カウントダウンの開始・一時停止・キャンセルを行う画面   |
|SCR-002   |アラーム一覧画面      |保存されたアラームを表示し、ON/OFFの切替、削除を行う画面      |
|SCR-003   |アラーム登録・編集画面 |アラームの新規登録および既存アラームの編集を行う画面         |
|SCR-004   |通知画面             |タイマーやアラームの通知時に表示される画面       |
|SCR-005   |削除確認ダイアログ     |削除する際にユーザーに確認を行う画面           |

## 3. 画面遷移図

```mermaid
graph LR;
  subgraph Timer
    SCR-001[SCR-001<br>タイマー画面<br>初期表示]
  end

  subgraph Alarm
    SCR-002[SCR-002<br>アラーム一覧画面]
    SCR-003[SCR-003<br>アラーム登録・編集画面]
    SCR-005[SCR-005<br>削除確認ダイアログ]
  end

  SCR-004[SCR-004<br>通知画面]


  %% タブ切替
  SCR-001 <--> |"F-CM-001 画面ナビゲーション"| SCR-002;


  %% タイマー
  SCR-001 -.-> |"F-TM-005 タイマー通知 /<br>F-AL-006 アラーム通知"| SCR-004


  %% アラーム
  SCR-002 --> |"F-AL-001 アラーム設定 /<br>F-AL-003 アラーム編集"| SCR-003
  SCR-003 --> |"F-AL-002 アラーム保存"| SCR-002
  SCR-002 --> |"F-AL-005 アラーム削除"| SCR-005
  SCR-005 --> |"削除確定 / キャンセル"| SCR-002
  SCR-002 -.-> |"F-TM-005 タイマー通知 /<br>F-AL-006 アラーム通知"| SCR-004

  %%通知後の復帰
  SCR-004 --> |"通知停止 / スヌーズ"| R["直前の画面に復帰"]
  
```
